1. Introduction

2. Getting Started

2.1 Creating an Account

  1. Open the website and go to Login (/login).
  2. Select the Register tab.
  3. Enter first name, last name, email, password, and barangay.
  4. Click Register, then sign in with your credentials.
You can also use Sign in with Google if enabled.
[ INSERT SCREENSHOT: Register tab on login page ]

2.2 Signing In & Out

  1. Go to Login and enter email and password.
  2. Click Sign in.
  3. To sign out: click your profile avatar (top-right) → Logout.

4. User Guide

4.1 Announcements & News

  • Announcements appear on the dashboard home page.
  • Click an announcement to read full details.
  • Some announcements include polls — vote when available.
  • News articles are in the news section; click to read more.
[ INSERT SCREENSHOT: Announcements on dashboard ]

4.2 Events

Browse: Programs → Events → click an event for details.

Register: Open event page → click Register (sign in required).

Track: Profile menu → My Events.

[ INSERT SCREENSHOT: Events list and event detail page ]

4.3 KK ID Card

  1. Profile menu → KK ID Card.
  2. Complete KK registration if prompted.
  3. Click Download to save as PDF.
[ INSERT SCREENSHOT: KK ID Card page ]

4.4 Account Settings

Profile menu → Account Settings → update info, photo, or password → save.

4.5 Resources & Transparency

  • Resources — browse and download federation files.
  • Disclosure Board — quarterly financial reports on the dashboard.
  • Process pages — compliance guides (BIR, COA, EFPS, etc.).
  • Chatbot — quick help on the dashboard.

5. Admin Guide

Admin only: These features require an account with the admin role. Admin links appear at the top of the profile menu.

5.1 Admin Dashboard

Path: Profile menu → Admin Dashboard (/dashboard/admin)

  • Platform stats: users, events, announcements, KK registrations.
  • Tabs: User Management, Event Participation, KK Registrations.
  • Analytics charts and event feedback review.
[ INSERT SCREENSHOT: Admin Dashboard ]

5.2 Creating Announcements

  1. Profile menu → Create Announcement.
  2. Enter title, content, category, optional image, and visibility dates.
  3. Publish. For polls: Create Poll Announcement.
[ INSERT SCREENSHOT: Create Announcement form ]

5.3 Creating Events

  1. Profile menu → Create Event.
  2. Fill in title, date, time, location, description, image.
  3. Track sign-ups in Admin Dashboard → Event Participation.
[ INSERT SCREENSHOT: Create Event form ]

5.4 Disclosure & User Management

  • Add Files SKCF — upload quarterly disclosure documents.
  • User Management — view and update user roles.
  • Moderator Logs — review moderator activity (admin only).
